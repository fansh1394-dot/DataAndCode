## 六、启动训练

### 6.1 B1-1 训练命令（本次要跑的）

```bash
cd /root/rivermind-data/MutilModel_3485988898

nohup python train_full.py \
    --route A \
    --config dual-fusion-b1 \
    --label-from keep \
    --data /root/rivermind-data/uav_data/data.yaml \
    --epochs 60 \
    --batch 32 \
    --imgsz 640 \
    --workers 16 \
    --device 0 \
    --cache none \
    --mm-dfs-weight 0.5 \
    --mm-dual-w-fuse-ir 1.0 \
    --mm-dual-w-fuse-ir-consist 0.0 \
    --name abl_B1-1_dual_ir_head \
    > /root/rivermind-data/train_B1-1.log 2>&1 &
```

看进度：

```bash
tail -f /root/rivermind-data/train_B1-1.log
```

### 6.2 参数说明

| 参数 | 取值 | 说明 |
|---|---|---|
| `--route A` | 随机初始化 | 路线 B/C 需配 `--pretrained` |
| `--config dual-fusion-b1` | **四头（B1）** | 比 `dual-fusion` 多一个 `fuse_ir` 头，loss 由 9 项变 12 项 |
| `--label-from keep` | 不改写 data.yaml | 映射已在上传的数据里写好了，别让脚本再改 |
| `--data ...` | **必须显式传** | 默认值是 AutoDL 路径 `/root/autodl-tmp/...`，在智川云上不存在 |
| `--epochs 60` | 本段轮数 | 150 轮跑不完可分段续训 |
| `--batch 32` | 24G 显存 | 实测占 14–17G；**OOM 就降到 16 或 8** |
| `--imgsz 640` | **不要降** | 目标中位仅 37 px，降分辨率伤精度 |
| `--mm-dfs-weight 0.5` | 保持与基线一致 | B1-1 是与 A0-2 对照，DFSC 不能动 |
| `--mm-dual-w-fuse-ir 1.0` | **L2 权重** | B1-1 的核心开关 |
| `--mm-dual-w-fuse-ir-consist 0.0` | **L3 关闭** | B1-1 必须保持 0.0；开到 B1-2 再说 |

> **不建议多卡**：本项目验证/绘图/保存只在 rank0 跑，其余卡空等；
> 且 `batch` 是 per-rank 的，多卡不改 `lr0` 等于偷偷降学习率，与之前实验不可比。单卡最省心。

### 6.3 断连防护

SSH 断开会杀掉前台进程。上面用了 `nohup ... &`，已经安全。

## 十、⚠️ 两个必须知道的前提

### 10.1 显存与硬盘

- **数据盘 50 GB 起**：数据 4.68 GB + 训练产物（`ResTest/` 每轮存检查点）会持续增长。
  空间不够就在控制台「数据盘扩容」。
- **`--cache disk` 不要开**：需额外约 37 GB 磁盘。用默认 `--cache none` 即可。

### 10.2 B1 方案第六节的硬前提尚未满足（影响效果预期）

`B1改造方案·融合头双坐标系监督.md` 第六节明确指出：当前训练集**完全不含单模态可见帧**
—— `prepare_mm_dataset.py` 已把这类样本丢弃。方案原文：

> 「即使 B1 给了融合头『在 IR 坐标系下成立』的监督，它也**从未在『RGB 失效』的样本上被训练过**
> —— 因为训练集里根本没有这种样本。」

**这直接影响 B1-1 的效果预期**：L2 能让融合头在 IR 坐标系下多一条监督通路，
但若训练集里不存在「RGB 失效」的样本，融合头很难学到「RGB 坏掉时靠 IR 兜底」的能力。

**建议**：先按现状跑一轮 B1-1 拿到数字；若 A 组 `fuse` 未达 0.1，
再考虑叠加数据配套（S1：数据生成保留困难帧；S2：模态 dropout 在线增广，
`mm_modal_dropout_*` 配置项已存在）重跑，把「数据前提」与「监督设计」两种因素**分开归因**。
