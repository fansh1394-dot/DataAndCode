## C1 · 门控激活正则 `L_gate`（P0）

### 问题依据
`diag_gate_stats.log` 显示 S6a 的 `GatedReliabilityFusion` 在 L48 门控 `g` 均值 0.4999、**std 0.0008**，L50 为 std 0.0002——门控冻结在中性 0.5，未学出任何区分度，等价于退化成 `fused=(rgb+ir)/2`。

### 原理
Zero-init 使 `g≡0.5` 是稳定不动点：只要 `ir` 与 `rgb` 的差异对最终 loss 没有独立贡献，梯度就会把 gate 压在 0.5。需要显式奖励「门控偏离中性」，即惩罚 `g` 的方差过小：

\[
L_{gate} = \frac{1}{|\mathcal{L}|}\sum_{l} \operatorname{ReLU}\big(\tau - \operatorname{std}(g_l)\big)^2
\]

- `τ`（`mm_gate_reg_target`）为目标门控标准差，默认 0.15（L46 已达 0.13，取略高值推动深层激活）。
- 只对 std 低于目标时产生梯度（ReLU），达标后自动归零，不会无界推大。
- 复用模块已暴露的 `last_gate_mean`；**需新增** `last_gate_std`（见下）。

### 改动 1.1 · `ultralytics/nn/mm/gated_fusion.py`

在 `GatedReliabilityFusion` 中新增一个可被外部读取的 std 标量。在 `forward` 末尾（`last_gate_mean` 之后）追加：

```python
        # 供 L_gate 正则与诊断读取：门控标准差（空间-通道维），detach 不参与反向；
        # 反向经由 forward 返回的 fused 特征流回 gate 分支，梯度有效。
        self.last_gate_std = gate.detach().std()
```

并在 `__init__` 的 `self.last_gate_mean = None` 后补：

```python
        self.last_gate_std = None
        self._mm_collect_gate = False   # trainer 打开后才累积，避免无谓开销
```

> 注意：`detach()` 只用于**诊断记录**，正则项的梯度从 `dual_loss` 侧经 `fused` 反传，此处不阻断。

### 改动 1.2 · `ultralytics/nn/mm/dual_loss.py`

在 `DualHeadFusionCriterion.__init__` 增加参数与状态：

```python
        gate_reg_weight: float = 0.0,
        gate_reg_target: float = 0.15,
        ...
        self.gate_reg_weight = float(gate_reg_weight or 0.0)
        self.gate_reg_target = float(gate_reg_target or 0.15)
        self.last_gate_reg = 0.0
```

在 `forward` 中新增一段（放在 `_head_consistency` 之后、`return` 之前）：

```python
        # ---- 门控激活正则（P0）：惩罚门控塌缩到中性 0.5 ----
        # 依据：diag_gate_stats 显示 L48/L50 门控 std≈0（冻结）。该项仅在模型末层
        # 为 GatedReliabilityFusion 且门控模块暴露 last_gate_std 时生效。
        if self.gate_reg_weight > 0:
            try:
                gate_reg = self._gate_activation_reg()
                self.last_gate_reg = float(gate_reg.detach())
                extra = extra + gate_reg * self.gate_reg_weight * batch_size
            except Exception as e:  # pragma: no cover
                LOGGER.warning(f"L_gate 计算失败，本次跳过: {type(e).__name__}: {e}")
                self.last_gate_reg = 0.0
        else:
            self.last_gate_reg = 0.0
```

新增方法：

```python
    def _gate_activation_reg(self) -> torch.Tensor:
        """惩罚 GatedReliabilityFusion 门控标准差低于目标值（ReLU 单边，达标即归零）。"""
        from ultralytics.nn.mm.gated_fusion import GatedReliabilityFusion
        stds = []
        for m in self.head.modules():
            if isinstance(m, GatedReliabilityFusion) and m.last_gate_std is not None:
                stds.append(m.last_gate_std.to(self.device, torch.float32))
        if not stds:
            return torch.zeros((), device=self.device)
        target = self.gate_reg_target
        # mean over layers of relu(target - std)^2
        pen = torch.stack([torch.relu(target - s) ** 2 for s in stds]).mean()
        return pen
```

> `last_gate_std` 由 forward 时的 `gate` 计算得出，是**同一前向**的张量；虽然 detach 掉了值，但 `pen` 项此时只依赖该标量快照——为让梯度真正回流 gate，需把 `last_gate_std` 改为**不 detach** 的版本，或直接在此函数内重新计算。推荐后者（见下方"C1 补充"）。

**C1 补充（梯度正确性）**：由于 `last_gate_std` 是 detach 标量，`pen` 对参数无梯度，会退化成常数。正确做法是在 `GatedReliabilityFusion.forward` 中**额外保留**一个非 detach 的 gate 引用供损失读取：

```python
        self._gate_raw = gate   # 非 detach，仅供 loss 侧取 std；不进 state_dict
```

并在 `_gate_activation_reg` 中改用 `m._gate_raw`：

```python
            g = getattr(m, "_gate_raw", None)
            if g is not None:
                stds.append(g.float().std())
```

`_gate_raw` 每次 forward 被覆盖、不参与序列化，`__getstate__` 中如已有清理逻辑则一并不保留（该属性非参数/缓冲，天然不落盘）。

## C4 · DAMSDet 可变形交叉注意力替换 offset 对齐（P1）

### 原理
当前 `ReliabilityAwareFusion` / `GatedReliabilityFusion` 用「单张 offset 图 → grid_sample 全局仿射/平移」。DAMSDet 的多光谱可变形交叉注意力改为**逐查询自适应采样**，对局部、非均匀失配更鲁棒，正对本项目「视角差异 + 局部错位」难点。

### 改动 4.1 · 新增 `ultralytics/nn/mm/deform_fusion.py`

保留现有对齐-融合框架，仅把「单点 grid_sample」升级为「多参考点可变形采样 + 门控残差」：

```python
"""Deformable cross-modal fusion (DAMSDet-inspired).

与 GatedReliabilityFusion 的超参/接口保持一致（inc, ouc, max_offset, base, gate），
因此可在 YAML 中原位替换，诊断脚本与验证流程无需改动。
差异：对齐从「单偏移 grid_sample」升级为「K 个可学习参考点的可变形采样聚合」，
对局部非均匀失配（视角差异导致）更鲁棒。
"""
import torch, torch.nn as nn, torch.nn.functional as F
from ultralytics.nn.modules.conv import Conv

class DeformableCrossModalFusion(nn.Module):
    def __init__(self, inc, ouc, max_offset=0.08, base="rgb", gate="channel",
                 n_points=4):
        super().__init__()
        self.c_rgb, self.c_ir, self.ouc = int(inc[0]), int(inc[1]), int(ouc)
        self.max_offset = float(max_offset); self.n_points = int(n_points)
        self.base_mode = str(base).lower(); self.gate_mode = str(gate).lower()
        hidden = max(min(self.ouc, 128), 16)
        self.rgb_proj = Conv(self.c_rgb, self.ouc, 1)
        self.ir_proj  = Conv(self.c_ir,  self.ouc, 1)
        # 每个参考点预测 (dx, dy, w)：K 点加权的可变形采样
        self.offset = nn.Sequential(
            nn.Conv2d(self.ouc * 2, hidden, 3, padding=1, bias=False),
            nn.BatchNorm2d(hidden), nn.SiLU(),
            nn.Conv2d(hidden, self.n_points * 3, 3, padding=1),
        )
        self.gate = nn.Sequential(
            nn.Conv2d(self.ouc * 2, hidden, 3, padding=1, bias=False),
            nn.BatchNorm2d(hidden), nn.SiLU(),
            nn.Conv2d(hidden, self.ouc, 1),
        )
        self.out = Conv(self.ouc, self.ouc, 3)
        nn.init.zeros_(self.offset[-1].weight); nn.init.zeros_(self.offset[-1].bias)
        nn.init.zeros_(self.gate[-1].weight);   nn.init.zeros_(self.gate[-1].bias)
        self.last_offset_abs_mean = None
        self.last_gate_mean = None
        self.last_gate_std = None
        self._gate_raw = None

    @staticmethod
    def _base_grid(b, h, w, device, dtype):
        yy, xx = torch.meshgrid(
            torch.linspace(-1, 1, h, device=device, dtype=dtype),
            torch.linspace(-1, 1, w, device=device, dtype=dtype), indexing="ij")
        return torch.stack((xx, yy), -1).unsqueeze(0).expand(b, -1, -1, -1)

    def _deform_sample(self, feat):
        b, _, h, w = feat.shape
        pred = self.offset(torch.cat((self.rgb_proj_out, self.ir_proj_out), 1)) \
            if False else self.offset(self._pair)
        d = pred.view(b, self.n_points, 3, h, w)
        base = self._base_grid(b, h, w, feat.device, feat.dtype)  # (b,h,w,2)
        outs = []
        for k in range(self.n_points):
            off = d[:, k, :2].permute(0, 2, 3, 1).tanh() * self.max_offset
            grid = (base + off).clamp(-1, 1)
            outs.append(F.grid_sample(feat, grid, mode="bilinear",
                                      align_corners=True, padding_mode="border"))
        wgt = d[:, :, 2].softmax(1).unsqueeze(2)   # (b,K,1,h,w)
        return sum(wgt[:, k] * outs[k] for k in range(self.n_points))

    def forward(self, xs):
        rgb, ir = xs
        rgb, ir = self.rgb_proj(rgb), self.ir_proj(ir)
        self._pair = torch.cat((rgb, ir), 1)
        rgb_w = self._deform_sample(rgb)
        ir_w  = self._deform_sample(ir)
        gate = torch.sigmoid(self.gate(torch.cat((rgb_w, ir_w), 1)))
        base_feat = 0.5 * (rgb_w + ir_w) if self.base_mode == "mean" else rgb_w
        fused = base_feat + gate * (ir_w - rgb_w)
        self._gate_raw = gate
        self.last_gate_mean = gate.detach().mean()
        self.last_gate_std  = gate.detach().std()
        return self.out(fused)
```

> 上面 `_deform_sample` 里 `self.offset` 的输入需同时供 rgb/ir 两路——实现时用一个显式 `pair = cat(rgb_proj, ir_proj)` 传入，避免两路各自算 offset。上式为示意，落地时整理为单一 `pair` 参数。

## C5 · COXNet 小波对齐 + GeoShape 标签分配（P1）

### 5A · 小波对齐（替换 offset grid_sample 的预处理）

新增 `ultralytics/nn/mm/wavelet_align.py`：对 RGB/IR 特征各做一级 Haar 小波分解，低频做对齐、高频保细节，再逆变换：

```python
"""Wavelet-based cross-modal alignment (COXNet CLFM-inspired).

把特征分解为低频(结构)与高频(细节)，仅对低频做 offset 对齐，避免高频小目标
细节被 grid_sample 插值抹平 —— 正对本项目小目标难点。
"""
import torch, torch.nn as nn, torch.nn.functional as F

def haarcascade_dwt(x):   # 一级 Haar 小波
    a = x[:, :, 0::2, 0::2]; b = x[:, :, 0::2, 1::2]
    c = x[:, :, 1::2, 0::2]; d = x[:, :, 1::2, 1::2]
    ll = (a + b + c + d) * 0.5
    lh = (a - b + c - d) * 0.5
    hl = (a + b - c - d) * 0.5
    hh = (a - b - c + d) * 0.5
    return ll, (lh, hl, hh)

def haar_idwt(ll, hf):
    lh, hl, hh = hf
    a = (ll + lh + hl + hh) * 0.5; b = (ll - lh + hl - hh) * 0.5
    c = (ll + lh - hl - hh) * 0.5; d = (ll - lh - hl + hh) * 0.5
    n, ch, h, w = ll.shape
    out = ll.new_empty(n, ch, h * 2, w * 2)
    out[:, :, 0::2, 0::2] = a; out[:, :, 0::2, 1::2] = b
    out[:, :, 1::2, 0::2] = c; out[:, :, 1::2, 1::2] = d
    return out
```

在融合算子中：`ll_rgb, hf_rgb = dwt(rgb_proj)`；`ll_ir, hf_ir = dwt(ir_proj)`；对 `ll_*` 做现有 offset+grid_sample 对齐；高频侧**不做几何变换**（或仅做门控残差）；最后 `idwt` 融合。这样全局结构错位由低频对齐吸收，小目标高频细节不被插值破坏。

> 该模块依赖 `imgsz` 可被 2 整除（640 满足）；padding 边缘用 replicate 补齐。

### 5B · GeoShape 标签分配（替换刚性 IoU）

在 `ultralytics/utils/tal.py` 的 `TaskAlignedAssigner` 中新增可选度量开关 `mm_assign_metric`：

- `"iou"`（默认，现状）→ 保持逐位不变。
- `"geoshape"` → 对齐分数改为 `α·IoU + β·形状相似度`，其中形状相似度用归一化宽高比的余弦：
  \[
  S_{shape} = \cos\big(\pi/2 \cdot (\text{aspect}_{gt} - \text{aspect}_{pred})\big)
  \]
  对小目标，IOU 对几像素平移极敏感，而形状项更稳定（COXNet 论点）。

在 `default.yaml` 新增：

```yaml
mm_assign_metric: iou      # (str) TAL 对齐度量：'iou'(默认) | 'geoshape'
mm_assign_shape_beta: 0.25 # (float) geoshape 模式下形状项权重
```

并在 `train_full.py` 增加两个 `--mm-assign-*` 参数与校验（非法值报错）。

### 验收标准
- `iou` 模式下 2-epoch 冒烟结果与改造前**逐位一致**（回归保护）。
- `geoshape` 模式下 only_ir 子集召回提升（论文主指标之一）。

## 附：为什么这些改动是安全的

1. **默认关闭**：C1/C4/C5 的所有新超参默认值 = 现状行为，`fuse_ir` 缺失时 `DualHeadFusionDetect` 逐位不变，`best.pt` 推理不受影响。
2. **不动物理分支顺序**：`branch_order` 恒为 `("rgb","ir","fuse")`，推理路径不变。
3. **诊断复用**：C4/C5 的新算子保持与 `ReliabilityAwareFusion` 相同的超参签名，`diag_fusion_attribution.py` / `diag_gate_stats.py` 无需改写即可对比。
4. **可回退**：C4/C5 各引入独立 YAML 配置与新 `--config` 别名，旧配置 `dual-fusion` / `-b1` / `-reliable` / `-gated` 一行不动。

> 校验基准：所有改动先在 2-epoch 冒烟 + `preflight_v2.py` 上验证，再进 100-epoch 正式训练；每项改动均设「主指标下降 > 0.005 即回退」的止损线。
