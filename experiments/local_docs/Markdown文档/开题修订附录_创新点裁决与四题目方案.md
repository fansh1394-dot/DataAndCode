## 1. 开题三个创新点的逐条裁决

| 开题创新点 | 声明内容 | 裁决 | 依据 |
|---|---|---|---|
| 三 · 跨模态可靠性动态融合 | 配准质量与单模态置信度共同决定融合权重 | **否证** | test 口径 `fusion_gain_over_rgb` 仅 +0.0016；C4 fuse 0.558835 低于 E1 0.568257（−0.0094）；S9_fix/C4/坐标系切换等七条修复路线全部否定 |

## 2. 修正后的项目创新点（全部有实测证据）

### 创新点 A · 双坐标标注语义不一致的发现与量化（领域空白）

- 两套标注**目标数量 100% 一致**（test both 帧 15874/15874，train 28381/28381）、
  **类别 100% 一致**（配对框类别一致 5291/5291 与 7138/7138），
  但框位置 IoU 均值仅 **0.0432**（85.2% 帧 < 0.10），配对框 IoU≥0.5 仅 **2.6%**（139/5291）。
- 数量与类别一致性**排除了标注错误的解释**：这是"同一目标的两个物理部位"（RGB 标机体、IR 标热源）的系统性现象。
- 热斑定位验证：IR 图最亮点到 IR 框中心残差中位 **5.59 px**，到 RGB 框中心 **44.07 px**（比值 7.88×），
  **97.2%** 的 IR 框更靠近热斑。
- 偏移 97.75% 单向（test dy 中位 +35.33 px，train +38.75 px，27/27 序列同向）。
- 文献空白佐证：高星开源多光谱检测项目（CFT 480★、YOLOv11-RGBT 729★、YOLO-MIF 264★、DEYOLO 185★）
  全部假设两模态已配准/共享坐标；处理非对齐的项目星标均 < 100。

### 创新点 B · 偏移的生成模型与可对齐精度的定量界定

偏移生成结构（[_diag_offset_structure.py](scripts/_diag_offset_structure.py)、[_verify_align_oracle.py](scripts/_verify_align_oracle.py)）：

```text
dy = A(seq) + B·(cy − 0.5) + ε
```

| 成分 | 实测 | 可处理性 |
|---|---|---|
| 视差项 `B·cy` | 序列内 corr(dy,cy) 中位 −0.59（test，85.4% 序列负）/ −0.73（train，95.3% 负）；解析 B ≈ −89 ~ −130 px/单位 cy | 解析计算 |
| 序列偏置 `A(seq)` | 跨序列 std 15.12（test）/ 21.45（train）px，范围 [−75, +101]；ANOVA 序列间方差占 51.1%/60.2%；与目标尺度无关（R²≈0.003），与序列平均位置无关（符号在 split 间翻转）；序列内缓慢漂移（前 4 帧 std(A)=1.19 px → 前 64 帧 6.01 px） | 前 4~8 帧在线估计即收敛（N=1 均值估计误差 3.6 px） |
| 帧内抖动 `ε` | 去视差后 ACF(1)≈0.48~0.51，时间常数 ≈2 帧，量级 ~5 px | 不可消除 |

**可实现的非 oracle 对齐精度**：`A+B·cy` 解析模型中位中心误差 **17.01 px**（= 0.6 个中位目标高度），
预测框与 GT 的 IoU 中位仅 **0.330**；逐序列仿射（N=64 帧拟合）仅微幅改善至 **15.51 px**。
这从机理上解释了 IoU 关联必然失效（97.4% 帧 < 0.5）。

### 创新点 C · 几何对齐收益为零的证据链

- per-frame oracle（每帧用自身标签构造性零误差对齐）重训早期融合：
  0.567959 vs E1 0.568984 = **−0.0010**。
- 可实现的对齐（序列级，残差 15~17 px）精度又不足（第 2.B 节）。
- **两头堵死**：对齐收益在"完美对齐"与"可实现对齐"两端均为零/不可达，
  界定了"先配准再融合"方法族在该场景的适用边界。

### 创新点 D · 决策级路由是唯一正向融合形态

- 零训练成本，帧级置信度路由（tau 0.30/0.50）：**+0.00635**，
  only_ir 帧召回 **0 → 98.19%**（652/664），路由准确率 94.99%，both 帧 FP 仅 +65。
- 唯一稳定的特征级正增益仅在 only_rgb 桶（75 帧，+0.0101）——
  融合的价值在**可见性互补**，不在特征融合质量。

### 创新点 E · 端侧完整闭环

双路采集 → letterbox 复现 → NMS-free 解码 → 帧级路由 → 告警的 RK3588 板端工程已实现；
RKNN 兼容性预检通过（TopK/Mod/Softmax 全部落 NPU）。

## 3. 四个小论文题目方案

四题关系：**题目一定义问题 → 题目二给几何侧方法 → 题目三给决策侧方法 → 题目四落地**。
证据链共享，互不重叠，合计新增训练 run 约 8~10 个。

### 题目一（发现型，最有希望）

**《可见光-红外目标检测中的双坐标系标注语义不一致：量化、成因与检测影响》**
Dual-Coordinate Annotation Inconsistency in RGB-IR Detection: Quantification, Causes, and Impact

| 项 | 内容 |
|---|---|
| 依托 | 创新点 A + C |
| 关键问题 | 融合方法普遍隐含"两模态共享标注坐标"，该假设何时成立？不成立时影响多大？ |
| 贡献 | 三层一致性核验协议（数量/类别/几何）+ 物理成因验证（热斑归属）+ 偏移生成模型 + oracle 对齐负结果 + IoU 关联失效的定量解释 |
| 最小实验 | 诊断已齐备；补 R1.1 序列级对齐重训（1 run，见附录 A）钉死 oracle 结论 |
| 新而不偏门 | 形态为标准的标注质量/基准分析论文（noisy labels 一脉）；现象本身无人系统报告过 |
| 闸门 | R1.1 结果落入第 A.6 节判定矩阵后定稿立意表述 |

### 题目二（方法型，题目一的方法续篇）

**《基于序列自适应偏移先验的非配准双光谱目标关联与检测》**
Sequence-Adaptive Offset Prior for Cross-Modal Association in Unregistered RGB-IR Detection

| 项 | 内容 |
|---|---|
| 依托 | 创新点 B |
| 关键问题 | 对齐不可行时，跨坐标候选如何可靠关联？ |
| 贡献 | `A+B·cy` 建成**软关联先验**（±17 px 容差、中心距离代价替代 IoU）；序列偏置在线估计（前 8 帧收敛，含缓慢漂移的滑动更新）；跨头一致性校验 |
| 形态 | 传统：检测器 + 关联模块 + 一致性损失 |
| 最小实验 | 关联精度 P/R/F1 闸门（匹配 Precision/Recall/F1 达标才继续）→ 检测对比（约 4 run） |

### 题目三（方法+协议型，唯一有正增益）

**《可见性感知的决策级双光谱融合：特征融合为何失效而路由有效》**

| 口径红线 | 进论文前必须在官方评测器全量复跑（自写管线 always_rgb 比官方低 0.0295） |

### 题目四（系统型，毕业论文主线）

## 附录 A · R1.1 序列级对齐重训实验设计（题目一判定实验）

> 状态：**已设计，未启动**（服务器 `v26_chain2b.sh` 在跑，硬约束"阶段间严禁并行"）。
> 启动时点：chain2b 全部 8 run 完成 + G0 闸门产出 σ 之后。

### A.1 目的

回答两个问题：
1. **可实现的序列级对齐**（非 per-frame oracle）能否带来融合增益？
2. oracle 的 −0.0010 是"对齐无用"还是"per-frame 拟合过拟合破坏时序一致性"？

### A.2 已知前提（不重复验证）

- 每帧单目标（多目标帧 = 0），both 帧框数 100% 一致 → Hungarian 一对一配对零跳过。
- per-frame oracle 是构造性零误差（center_err = 0，IoU 中位 0.740），**任何非 oracle 方案精度必低于它**。
- 序列级仿射（N=64 帧拟合）中位 center_err 15.51 px；`A+B·cy` 解析模型 17.01 px。
- 原实验清单 R1.0 的验收线"逐序列 RMSE ≤ 2px 占比 ≥ 80%"**已知必不达标**（残差量级 15+ px），
  本实验不设该闸门，改为"记录残差 + 照跑"，因为科学问题是"可实现精度（15~17 px）的对齐是否有效"。

### A.3 数据构建（新脚本 `scripts/data/build_reg_seq_dataset.py`，服务器端 .sh 调用）

输出数据集 `uav_data_v2_reg_seq/`（**不改动** `uav_data_v2/` 与全局 data.yaml）：

```text
uav_data_v2_reg_seq/
  data.yaml            # path 指向本目录；labels.ir = labels（vis 口径，与原 data.yaml 同约定）
  images/              # 原样软链 RGB
  images_ir_reg/       # 逐帧 warp 后的 IR 图（cv2.warpAffine, bilinear, 填充=该图中位数）
  labels/              # both 帧 = RGB 标签；only_ir 帧 = IR 标签经同序列 M_seq 变换后写入；only_rgb 空
  labels_ir_reg/       # 变换后 IR 标签（诊断用，训练不读）
  _reg_meta.json       # 每序列矩阵 + n_pairs + 拟合/验证残差 + 降级标记
```

配准拟合协议（R1.1-seq，上界口径）：
1. 每序列收集共轭点对：`labels/` 与 `labels_ir/` Hungarian 配对（代价 = 中心距 + 0.5·尺寸差，同诊断脚本）。
2. 用**该序列全部帧**的点对拟合 2×3 仿射（最小二乘；条件数 > 1e9 或 x/y 跨度 < 8 px 时降级为纯平移 A(seq)）。
3. only_ir 帧无共轭点对，其标签用同序列 `M_seq` 变换。
4. 出画处理：变换后框中心出画或面积存留 < 50% 的框丢弃并计数入 meta。
5. 序列级统计入 `_reg_meta.json`：median/mean center_err（对全部 both 帧）、IoU 中位、降级序列清单。

同时记录 **R1.2-online（可选，部署口径）** 变体：每序列只用前 8 帧估计（与诊断脚本 N=8 协议一致），
数据集另存 `uav_data_v2_reg_seq_online/`。优先级低于 R1.1-seq，可后补。

### A.4 训练协议

| 项 | 规定 |
|---|---|
| 目录 | `ResTest/v2c_R1s_seqalign_s0`（跑前确认无残留 `results.csv`） |
| 配置 | **逐字段继承 `ResTest/v2c_R1_reg_early_s0/args.yaml`**，仅允许改：`name`、`data`（指向新数据集）。启动前 diff 断言仅这两处差异 |
| 代际 | 保持 YOLO11 early 配置——oracle run（0.567959）与 E1（0.568984）均为该代，**同代才可比**。v26 侧无 early 配置，若需 v26 版须先补配置与同代基线，不进本轮 |
| 轮数/精度 | 与 oracle run 一致（150 ep / fp32），不新增任何超参搜索 |
| 启动核验 | mtime + pidfile + pgrep 三项；日志内容不可信（历史教训） |
| 前置 | chain2b 完成 + G0 产出 σ；GPU 空闲 ≥ 19000 MiB 闸门 |

### A.5 评测协议

- `scripts/eval_split.py` 全量 test（16917 帧），eval yaml 落派生目录，不动全局 data.yaml。
- 输出四方对照表：E1（0.568984）/ oracle（0.567959）/ R1.1-seq / （可选 R1.2-online）。
- 附分桶（both/only_ir/only_rgb）与配准残差表的联合分析：
  按每序列残差分档，检验"残差小的序列是否增益更大"（残差-增益相关性）。

### A.6 判定矩阵（σ 取 G0 产出；G0 之前可用 E1 两种子差 0.0057 作代理上限）

| 结果 | 结论 | 论文动作 |
|---|---|---|
| R1.1 − E1 > σ | **序列级对齐有效** | oracle 负结果改写为"per-frame 拟合过拟合破坏时序一致性"；题目二增加"对齐作预处理"变体；题目一亮点升级 |
| \|R1.1 − E1\| ≤ σ | **对齐全谱无效**（0 ~ 17 px 精度两端均无收益） | 题目一"边界界定"证据链闭合；方法重心转向关联与路由（题目二/三） |
| R1.1 − E1 < −σ | **对齐有损** | 先查插值模糊/出画丢弃率再判；若确认，补写"warp 破坏 IR 热斑统计特性"，仍入题目一 |

### A.7 验收指纹（防静默失效）

1. 构建报告：序列数 = train 160 + val + test 91 全部有矩阵；降级序列清单非空且逐条有因；
   only_ir 标签变换丢弃计数入 meta。
2. backgrounds 一致性：新数据集 cache 扫描 `labels/`，train backgrounds = 58（only_rgb 数）、
   test = 75（only_ir 帧已有变换后标签，不再是背景）。
3. A/B 可视化：抽 3 个序列做"warp 后 IR 框 vs RGB 框"叠加图，人工确认贴合（对照 38 px 偏移基线）。
4. 训练启动：mtime + pidfile + 进程存在三项同时成立。
5. 评测：both 桶 mAP 与 E1 both 桶同量级（±0.05）作 sanity，异常即停。
