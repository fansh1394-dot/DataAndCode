## 0. 冻结协议（所有 run 必须逐项满足）

### 0.1 环境

### 0.2 训练协议

- 输入 `--imgsz 640`；**`--batch 32`（全清单统一，与服务器历史融合线一致）**；`nbs=64` 下 `accumulate=2`，等效批仍为 64
  - ⚠️ **batch 不是自由参数**：`accumulate` 只保证**梯度等效**，但 BN 运行统计量与单批增强样本数随 batch 改变，故全清单必须统一取值
  - ⚠️ 显存前提：fp32 + batch 32 下，双头融合配置（E4）峰值约 18.1~18.5G，单模态基线约 8~10G；启动前必须实测空闲显存，不足则**整份清单统一**回退 batch 16（不可部分 run 用 16、部分用 32）
- `--amp false`（fp32，所有 run 显式关闭 AMP）
- `--epochs 150`（headline）；`close_mosaic: 15` → ep136–150 关 mosaic
- `--workers 4`、`--safe-augment`、`--seed k`
- 优化器：`epochs ≥ 22` 自动落 **SGD lr0=0.01**（465 iter/epoch × 150 ≫ 10000），本清单所有 run 同优化器族，**可直接横比**
- 每次务必新建目录；`--route A`（随机初始化）除非显式说明

### 0.3 评测协议（冻结，不得漂移）

- **域内一律 `test`（16917 帧，完全未参与训练）**；`val`（12170 帧）只用于早停与模型选择，**其数字不得写入结论**
  - 已量化：val 系统性乐观 **0.1391~0.1865**（E1 −0.1391、E3 −0.1865、C4 fuse −0.1538）
- 入口：`python scripts/eval_split.py --split test`；结果落 `ResTest/_test_eval/<name>_test.json`
- 双头/四头模型必须**分路报告**：`rgb / ir / fuse / fuse_ir`
- 分桶报告：帧类型 `both / only_rgb / only_ir`（来自 `metadata/{split}.json` 的 `kind`）
- **融合增益只引用 `fusion_gain_over_rgb`**；`fusion_gain_over_ir` 非独立（= (fuse − ir) + gain_rgb），禁用

### 0.4 统计协议

- **噪声带 σ**：由 `E1` 与 `E4` 各 3 种子（s0/s1/s2）的 **test mAP50-95 标准差**给出，`σ = max(std_E1, std_E4)`
- **只在两个关键判定点**强制 3 种子：① `E4 vs E1` 融合增益 ② `G1 vs E1` GeoShape 增益。其余对照单种子 + σ 判读
- 任何"增益"必须 `> σ` 才可称为结论；否则记为噪声
- 汇总走 `scripts/summarize_v2_results.py`，**禁止手工挑最优数字**
- 每个 run 记录：配置/种子/代码版本/权重/日志/原始 JSON

### 0.5 工程协议（历史事故的硬约束）

- 多步远程逻辑**必须落成服务器端 `.sh` 再 `bash <script>`**（PowerShell 双引号中 `$()`、`cut -f1` 会被当子表达式解析）
- 启动后只认 **mtime + pidfile + `pgrep -f train_full.py`**；日志内容可能是上一次的残留，不可单独采信
- pidfile 防并发；`run_remote.ps1` 重试会导致并发进程
- `DualHeadDetectionValidator` 独立使用时必须手动补 `validator.data` / `validator.device`，并用 `MultiModalDetectionValidator.build_dataset` 建同一套 loader 注入

### 0.6 标签口径三态（`--label-from`）

| 取值 | rgb 标签目录 | ir 标签目录 | 用途 |
|---|---|---|---|
| `vis` | `labels` | `labels` | 仅可见光标签（E1） |
| `ir` | `labels_ir` | `labels_ir` | 主标签指向 IR（**IR 单模态必用**） |
| `dual` | `labels` | `labels_ir` | 双标签（所有双头/四头配置） |

> 必须同时给 `--single-modal x` 时 `--label-from ir` 才得到公平 IR-only；`--label-from dual` + `--single-modal x` 是**错配对照**（历史 0.2074 的来源）

## 4. 阶段 1 · 闸门实验（配准上界 R1 + 口径分解 Q1）

### 4.1 R1 · 已配准早期融合上界（**选题四 B5，也是全项目 thesis 的 paper-killer**）

**为什么必须先跑**：选题一 / 三 / 四共用同一底座假设——"非对齐是性能瓶颈"。若把 IR 配准到 RGB 坐标系后性能并不提升，则整个底座塌陷，三个选题同时失去立题依据。因此 R1 必须排在**任何子方向立项之前**。

**可行性（已核实）**
- `scripts/calib/regis.py` 已提供 `fit_from_points`（`cv2.estimateAffine2D` RANSAC，含 RMSE 验收线 2px）与 `align_ir`（warpAffine/warpPerspective）
- `scripts/calib/calib_dualspec.py`、`regis_online.py` **仍是 NotImplementedError 骨架**，本路线不依赖它们
- 数据基础：`both` 帧 11601 帧，两套标签的归一化框中心差 `mean|dx|≈0.030~0.039`、`mean|dy|≈0.074~0.080`、`max|dx|` 达 0.74 —— 存在真实可拟合的几何偏移

**R1.0 · 数据工程（新增脚本，落成服务器端 `.sh`）**
1. 读 `metadata/*.json` 取 `both` 帧；对每帧把 `labels/<stem>.txt` 与 `labels_ir/<stem>.txt` 的框按**中心邻近 + IoU** 做贪心配对，得 `pts_ir → pts_rgb` 共轭点对
2. **按序列**拟合仿射（每序列 ≥20 对，不足回落全局）；`fit_from_points(model="affine", ransac_px=3.0)`
3. 记录每序列：`n_pairs / inliers / rmse_px / max_err_px / accept`
4. 用 `align_ir` 把 IR 逐帧 warp 到 RGB 画幅，生成 `uav_data_v2_reg/`：
   - `images_ir` 全部替换为 warp 后图像
   - 标签：`both` 帧沿用 RGB 标签；`only_ir` 帧把 IR 标签按同一 `A` 变换后写入
   - 保留 `_reg_meta.json`（每序列矩阵 + 质量）
5. 产出 `calib/reg_meta_v2.json` + 配准质量报告表

**闸门 G1（关键判定 ①，决定阶段 3 的选题一/三/四是否立项）**
- **情形 A**：`R1.1 − E1 < σ` → 对齐不能带来实质增益 ⇒ **非对齐不是主因**。选题一/三/四的底座塌陷 → **停止其阶段 3 专项**，改走 `T2`（选题二，模态健康度）/ `T5`（选题五，小目标）/ `T6`（选题六，部署）。R1 作为"非对齐代价量化"的**负结果证据**写入毕设（配"两套标注 IoU 0.0432"的几何证据）
- **情形 B**：`R1.1 − E1 > σ` **且** `R1.1 − E4 > σ` → 对齐仍是瓶颈，且朴素早期融合在配准后能超过现最强方法 ⇒ 选题一/四立项，`R1`（B5）入选题四基线表，同时暴露"现方法的融合算子没吃到对齐红利"的缺陷（选题四的直接动机）
- 边界情形：`R1.1 − E1 > σ` 但 `R1.1 − E4 < σ` → 对齐有增益但现方法已部分吃掉 ⇒ 选题一/四**降级**为"边界条件分析"，不作为主论文

## 8. 明确砍项（test 口径已否证，不再投入）

| 砍掉 | 理由 |
|---|---|
| `A4` / `A5` / `S3` 融合掩膜类配置 | `--mm-fusion-rgb-mask` 削弱 RGB 通路，融合分支性能下降 |
| 任何以"提升 fuse 头全量 mAP"为端点的实验线 | `fusion_gain_over_rgb` test 仅 0.0016，fuse 反低于纯 RGB-only |
| 伪融合续追（`S9_fix` / `C4` 诊断 / 融合头判别） | 根因已定：**坐标错配**，非融合算子问题 |
| 旧 `G2~G4`（IR 单模态相关历史配置） | 被 `--label-from ir` 修复后的公平基线取代 |
| `N0~N3` 变体重训 | 降级为 **eval-only**（不重训，只复用权重出 test JSON） |
| `fuse_ir` 作为部署输出 | 无实质收益（全量 +0.0077，only_ir 桶 +0.0015） |
| 把 `fusion_gain_over_ir` 写进论文 | 非独立指标（= (fuse − ir) + gain_rgb） |
