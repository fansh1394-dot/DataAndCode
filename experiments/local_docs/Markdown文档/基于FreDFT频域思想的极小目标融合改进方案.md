# 基于 FreDFT 频域思想的极小目标融合改进方案（LFCF）

- 日期：2026-11-05
- 基线模型：`yolo26n-mm-dual-fusion-concat`（配置 `dual-fusion`，四头 rgb / ir / fuse / fuse_ir）
- 基线权重：`mdp150_M0_concat_s0`，test fuse 头 mAP50-95 = 0.7637
- 参照文献：*FreDFT: Frequency Domain Fusion Transformer for Visible-Infrared Object Detection*（arXiv 2511.10046，2025，预印本）
- 硬约束：RK3588 端侧 int8、640 输入、当前端到端 78.57 ms / 12.7 FPS；**不允许引入 FFT/复数运算**
- 现状诊断：lt16 桶 AP50 = 0.93、R@0.25 = 0.89，但 AP75 仅 0.54 → 瓶颈是**定位与边界精度**，不是检出率

---

## 1. 结论与边界

本方案的核心主张只有一句：
> **当前融合是「拼接 + C3k2」，等价于对两模态做加权平均；平均会抹平高频边缘，而极小目标的判别信息正集中在高频。把融合改为「低频加权 + 高频选择」，是本方案唯一的机制来源。**

必须同时写清楚三条边界，避免过度声称：

1. 频域手段**不解决**分辨率量化问题。已验证唯一有效的 +2.6σ（640 训 + 800 推）来自输入分辨率，频率分解不是它的替代品。
2. 本方案是**假设驱动**，尚无论文数值支撑（所引 arXiv 为预印本，海报结论未核实）。
3. 若 Step 0 诊断不成立，方案直接终止，不进入训练（见第 7 节）。

---

## 2. 从 FreDFT 借什么、不借什么

| FreDFT 的要素 | 本方案取舍 | 理由 |
|---|---|---|
| 高低频分解后分别融合 | **借** | 核心机制 |
| 高频增强（LFEM） | **借**，仅做残差，不加网络 | 小目标能量在高频 |
| 跨模态频域注意力（MFDA） | **借思想**，实现为通道门控 | 端侧 attention 代价高 |
| 真正的 DFT / 复数乘 / IFFT | **不借** | RKNN 对 `torch.fft` 与复数算子支持差，常退化到 CPU |
| 四个尺度全插 | **只插 P3 / P4** | lt16 与 16–32 桶都落在 P3/P4；P5 stride=32 已把 8 px 目标混叠 |
| 单头检测 | 不改 | 我们保留四头监督 |

**数学等价性说明**（这是不借 FFT 的合法性依据）：
固定核卷积在频域等价于乘性滤波。因此 `L = k_gauss * X`、`H = X − L` 就是「低通 / 高通分解」，与 DFT 域的低通、高通滤波是同一线性算子，只是实现方式不同。导出到 RKNN 后只是普通卷积，不产生特殊算子。

## 3. 模块设计：SpectralRefine（LFCF）

输入：同一尺度的 RGB neck 特征 `R`、IR neck 特征 `I`，形状均为 `(B, C, H, W)`。
输出：同形状的融合精炼特征。

### 3.1 三步

1. **带分解（零参数）**
   - `L_X = k_gauss ⊛ X`，`k_gauss` 为 3×3 二项式核 `[1,2,1]ᵀ·[1,2,1]/16`，以 `register_buffer` 注册，不参与训练
   - `H_X = X − L_X`（残差即高通）
2. **低频：退化加权**
   - `w = σ(Conv1×1(concat(L_R, L_I)))`，`w ∈ (0,1)^{C×1×1}`（通道级，全局池化后计算）
   - `L = w ⊙ L_R + (1−w) ⊙ L_I`
3. **高频：能量选择（不做平均）**
   - `g = σ(Conv1×1(concat(|H_R|, |H_I|)))`
   - `H = g ⊙ H_R + (1−g) ⊙ H_I`
4. **重建**：`X_out = Conv1×1(L + H)`

### 3.2 参数与算子

| 尺度 | C | 1×1 卷积数 | 参数量（约） |
|---|---|---|---|
| P3 | 64 | 3 | 6k |
| P4 | 128 | 3 | 24k |

算子集：`Conv2d(1×1)、Sub、Abs、Sigmoid、Mul、Add、GAP`。**全部为 RKNN 常规算子，无 FFT、无 spatial softmax。**

### 3.3 代码骨架

```python
class SpectralRefine(nn.Module):
    """低频退化加权 + 高频能量选择。固定高斯核，无 FFT。"""

    def __init__(self, c):
        super().__init__()
        binom = torch.tensor([1., 2., 1.])
        k = (binom[:, None] * binom[None, :]) / 16.0
        self.register_buffer("k", k.view(1, 1, 3, 3).repeat(c, 1, 1, 1))
        self.c = c
        self.gate_low = nn.Conv2d(2 * c, c, 1)
        self.gate_high = nn.Conv2d(2 * c, c, 1)
        self.out = nn.Conv2d(c, c, 1)

    def bands(self, x):
        lo = F.conv2d(x, self.k, padding=1, groups=self.c)
        return lo, x - lo

    def forward(self, r, i):
        lr, hr = self.bands(r)
        li, hi = self.bands(i)
        w = torch.sigmoid(self.gate_low(torch.cat([lr, li], 1)))
        l = w * lr + (1 - w) * li
        g = torch.sigmoid(self.gate_high(torch.cat([hr.abs(), hi.abs()], 1)))
        h = g * hr + (1 - g) * hi
        return self.out(l + h)
```

注：`gate_low / gate_high` 直接用全分辨率 1×1 卷积即可；若显存或时延紧张，可改为「GAP → Linear → 通道标量」，与 3.1 的描述一致。两种实现都必须做一组对照，避免写成"我们用通道门控"却实际用了空间门控。

| 项 | 评估 |

| 额外算子 | 1×1 Conv、逐元素加减乘、Sigmoid，无特殊算子 |

## 6. 实验设计

统一协议：150 ep、`batch=32`、`imgsz=640`、`seed=0`、`amp=false`、`label-from dual`，与 `mdp150_M0_concat_s0` 逐项对齐。

| arm | 融合方式 | 目的 |
|---|---|---|
| A0 | 现有 `Concat + C3k2`（即 `s0`） | 基线 |
| A1 | 高低频分解 + **低频平均 + 高频平均** | 隔离"分解"本身 |
| A2 | 高低频分解 + 低频平均 + **高频选择** | 隔离"选择"机制（本方案核心） |
| A3 | **低频退化加权 + 高频选择**（完整 LFCF） | 完整方案 |

### 6.1 判定线（前置写死）

基线三种子（s0 / s1 / s2，test，fuse 头）：

| 指标 | s0 | s1 | s2 | 均值 | σ | 判定线（均值+2σ） |
|---|---|---|---|---|---|---|
| lt16 AP50-95 | 0.5354 | 0.5556 | 0.5348 | 0.5419 | 0.0118 | **0.565** |
| lt16 AP75 | 0.5392 | 0.5677 | 0.5546 | 0.5538 | 0.0143 | **0.582** |
| 总体 mAP50-95 | 0.7637 | — | — | — | 0.0094 | 护栏 **≥ 0.7449** |

- **保留条件**：lt16 AP50-95 ≥ 0.565 **且** lt16 AP75 ≥ 0.582 **且** 总体 mAP50-95 ≥ 0.7449。
- **专项指标**：无 GT 帧的 FP/frame、FPR@0.25；R@0.25 不低于基线三种子的最低值（0.8896）。
- **诊断指标**：融合头对 IR 半边的响应比（"IR 零响应"问题的量化），A3 应高于 A0；若持平，说明模块只是装饰，不构成方法贡献。
- **止损规则**：
  - A1 正向、A2 不正向 → 判定"选择"机制无效，方案降级为普通带分解，不占创新点；
  - A2 正向、A3 不正向 → 退化加权是负担，交付 A2 版本；
  - A1/A2/A3 全部不达标 → 放弃频域路线，回到尺度蒸馏。

### 6.2 结论表述约束

1. 只允许写"lt16 桶 AP50-95 由 0.542 提升至 X，约为 2σ 判定线以上/以下"，不允许写"显著提升"。
2. 时序稳定性与跟踪补检的收益不得计入检测 AP。
3. 引用 FreDFT 时必须标注为 2025 年 arXiv 预印本；其模块细节与数值须回原文核对。

## 7. Step 0：训练前的零成本诊断（必须先做）

不训练、不改模型，只对已训好的 `mdp150_M0_concat_s0` 挂 hook，在 46 / 48 / 50 三层特征上统计：

| 诊断量 | 计算 | 判据 |
|---|---|---|
| 高频能量占比 | `‖H‖₂ / ‖X‖₂`，H 为 `X − k_gauss*X` | 若 P3 的高频占比 < 10%，说明该层几乎没有可融合的高频信息，方案前提不成立 |
| IR/RGB 高频能量比 | `‖H_IR‖₂ / ‖H_RGB‖₂`（对应支路的 27/39、30/42） | 若该比值接近 0 或远小于 1，则"IR 零响应"的根因在高频段，LFCF 对症 |
| 与 lt16 存在的相关性 | 每帧标记是否含 lt16 GT，计算高频占比与标记的 point-biserial 相关 | 若相关系数 < 0.1，说明高频与极小目标无明显关联，终止方案 |
| 时序抖动基线 | 见《VideoFusion核验与检测侧时序一致性指标定义》第 4 节 | 作为后续对照，不阻塞本方案 |

**终止条件**：上表任一项落入否判决，方案即终止并记录原因，不进入 A1–A3 训练。

### 7.1 实测结果与判读（2026-11-05）

执行脚本：`scripts/diag_spectral_s0.py`（帧级，614 帧、s0 权重）、`scripts/diag_spectral_v2.py`（对象级，552 GT）。

**S0（帧级，融合颈输入）**

| 项 | 实测 | 原假设 | 判定 |

| P4 / P5 | RGB 40.1% / 38.0%，IR 44.8% / 45.5% | — | — |
| IR/RGB 高频 RMS 比 | P3 1.048、P4 1.060、P5 1.061 | 远小于 1（IR 高频被压制） | **不成立**：IR 进入融合前高频与 RGB 相当 |

| 桶 | 模态 | n | ratio_in | ratio_bg | delta 中位 | 正例占比 | 符号检验 p |
|---|---|---|---|---|---|---|---|
| lt16 | RGB | 154 | 0.0225 | 0.0058 | +0.0173 | 83.1% | <1e-4 |

**特征足迹**：lt16 在 P3（stride=8）上的等效单元数中位 **1.49**，51.9% 的目标不足 1.5 个单元。

**判读**

1. 图像级：极小目标的高频占比约为背景环的 3.9 倍，RGB 与 IR 均显著 → 高频信息**存在且可分离**。
2. 但**不具极小目标特异性**：16–32、32–64、>64 桶的 delta 同样显著甚至更大，本质是"目标 vs 天空"的通用边缘对比。且 lt16 的 AP50 已达 0.93，"有没有"不是瓶颈，因此该证据只能支撑定位方向的假设，不能支撑"频域是极小目标专属机制"的表述。
3. 特征级：lt16 在 P3 上仅约 1.49 个单元，局部带分解没有空间支撑 → **把模块插在融合颈 C3k2 输出（48 / 51，及 54）在结构上无效**，与训练结果无关。

**结论：原 LFCF 设计作废（位置错、作用域错、不具特异性）。**

若仍要走频域路线，仅剩一条形态：**输入侧/浅层（stride 1–2）的带通前端**，代价是新增端侧算子与 int8 量化风险，收益仅为"可能改善 AP75"这一未验证假设。相比之下，尺度方向（800 教师 → 640 学生）的推理代价为零，优先级更高；但其中「伪标签替换」形态已在 §7.2 被实测否决，改走跨分辨率特征蒸馏。

原判定规则中 `|r| ≥ 0.1` 的口径存在缺陷：P3 的 −0.100 会"擦线通过"但符号为负，属误判。后续诊断一律同时报**符号方向**与显著性，不再单用绝对值阈值。

### 7.2 尺度蒸馏：伪标签路线被否决，转跨分辨率特征蒸馏（2026-11-05）

原推荐的「800 教师伪框替换 GT → 重训 640」在开工前做了零成本核验，结论是否决。

**实测：教师（800 推理）框与 GT 的一致性**（test 552 GT，`fuse` 头，conf ≥ 0.30，脚本 `scripts/diag_pseudolabel_ceiling.py`）

| 桶 | 匹配率 | IoU 中位 | ≥0.75 占比 | ≥0.90 占比 | 640 对照中位 |
|---|---|---|---|---|---|
| lt16 | 94.8% | **0.803** | 69.9% | 27.9% | 0.785 |
| 16–32 | 98.4% | 0.867 | 88.9% | 52.9% | 0.867 |
| 32–64 | 98.7% | 0.901 | 95.9% | 66.2% | 0.911 |
| >64 | 99.0% | 0.933 | 99.5% | 85.6% | 0.925 |

**否决依据（三条）**

1. **信息论上劣于原始 GT**：GT 是评测基准，与自身的 IoU 恒为 1.0；教师框中位只有 0.803。把 GT 换成教师框，等于把标签误差中位值抬到 0.20。一个完美拟合这些伪标签的学生，其上限就是教师自身的 AP（800 下 lt16 AP50-95 = 0.5731），而 640 学生拿不到 800 的网格密度，实际只会更低。因此该路线**按原设计不可能超过现有基线**。
2. **800 的增益来自网格密度，不是标签信息**：原图约 596×450，640 训练已是上采样。lt16 在 640/P3 约 1.25 个特征单元，在 800/P3 约 1.6 个。这部分空间采样密度无法通过标签传给 640 学生。
3. **教师框相对 640 几乎没变**：lt16 IoU 中位仅从 0.785 升到 0.803，说明换分辨率并没有产出「另一套更准的框」，只是把噪声换了个方向。

**替代方案：跨分辨率特征蒸馏（本次执行）**

- 教师 `mdp150_M0_concat_s0` 按 `imgsz=800` 前向；学生保持训练 `imgsz=640`。
- 只蒸馏**融合颈 P3/P4/P5 的 C3k2 输出**（层 48 / 51 / 54，即 fuse 头的输入），教师特征由 `F.interpolate` 对齐到学生空间尺寸（100→80、50→40、25→20，均为整数倍，无插值相位误差）。
- 只做特征 KD，**不做输出 KD**：教师输出是 `dict(branch → raw)`，且 800/640 的 anchor 数不相等（25² vs 20²），无法逐 anchor 对齐。
- 前景掩码：四头模型输出不是标准 Detect bundle，无法解码 dense 框，改用全图均匀掩码（等价于 FitNets 式特征回归）。

2. 特征 KD 的权重沿用仓库默认（`distill_weight 1.0`、`distill_feature_weight 1.0`、`distill_feature_warmup 10`），未做标定；若 2 轮冒烟的 KD 项量级与检测损失严重失衡，需先调权重再跑满。
3. 这是**迁移假设**而非已验证机制：800 的特征是否包含 640 可复现的信息，本身就是要被这次实验检验的问题。若跑满后三项判定均不达标，该方向应与伪标签路线一并归档为负向结论。
