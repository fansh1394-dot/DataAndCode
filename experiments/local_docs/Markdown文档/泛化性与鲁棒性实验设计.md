## 〇、实验分类的判据（先厘清边界）

实验分类的**唯一判据**是"测试数据是否来自训练分布之外"：

| 判据 | 消融实验 | 泛化实验 | 鲁棒性实验 |
|---|---|---|---|
| **测试数据来源** | 与训练同分布（自己的 test） | **不同来源**（外部数据集） | 与训练同分布（自己的 test） |
| **施加的变化** | 网络结构 | 数据域 | 输入扰动 |
| **回答的问题** | 模块有没有用 | 能否迁移到新环境 | 恶劣输入下是否稳健 |

**关键澄清**：
- 多训两个单模态模型**本身不是泛化实验**——只有当它们在**外部数据集**上测试时才构成泛化实验。
- 在自己的测试集上施加扰动（加噪、加视场偏移）属于**鲁棒性**，不是泛化。

## 〇之二、2026-09-22 修订说明（**必读，影响 R2 全部设计**）

### 人工配准方案已判定失败

此前 R2 的设计前提是"可通过人工肉眼配准把两模态对齐到 2px 量级"。
**该前提已被推翻** —— 人工配准误差过大，根本配不准。

### 实测证据

对 Anti-UAV300 实测（34 对样本）：

| 指标 | 数值 |
|---|---|
| RGB 与 IR 框中心归一化距离（中位） | **3.62 pp** |
| 同上（均值 / 最大） | 4.38 pp / **10.85 pp** |
| 距离 > 1 pp 的样本占比 | **100%** |

即：两模态的视场差异是**系统性的、每帧都存在的**，不是可以通过标定消除的随机残差。

### 由此产生的三个后果

**后果一：不能再把"配准误差"当作可调的小扰动。**
旧 R2 设想的是"施加 0/2/4/8/16px 平移看衰减"，隐含假设是"0px 是可达的理想态"。
既然 0px 不可达，这个设计失去了基准点。

**后果二：新方案不再依赖任何配准，改为「双标签独立监督」。**
RGB 用 `labels/`（visible.json）、IR 用 `labels_ir/`（infrared.json），
各模态用**本相机下的真实框**，彻底绕开跨模态坐标映射。

**后果三：R2 应重构为「非对齐条件下的鲁棒性」**，即论证
"在视场本就不对齐的现实条件下，本方法依然稳健"，而不是"配准到多准才够用"。

### 对其它实验的连带修正

| 项 | 旧设计 | 新设计 |
|---|---|---|
| **A2**（仅红外单模态） | 用可见光标签 | **必须用 `labels_ir/`**（infrared.json） |
| **G2–G4**（红外泛化） | 未区分标签来源 | 单模态红外模型一律用 IR 坐标系标签 |
| **G5**（融合退化） | 隐含"配准良好" | 明确说明"两模态视场天然不重合" |
| **R2** | 配准误差 0–16px 曲线 | **非对齐鲁棒性**（见第三节重构版） |

## 二、泛化实验（5 项）

### 2.1 单模态外部泛化（G1–G4）

**目的**：验证各模态特征提取器在**未见过的数据域**上的迁移能力。

| 编号 | 训练模型 | 测试集 | 泛化维度 | 强度 |
|---|---|---|---|---|
| G1 | `single_rgb` | DUT Anti-UAV | 跨设备（可见光） | 强 |
| G2 | `single_ir` | Anti-UAV410 | 跨数据集（红外，同系列改进版） | 中 |
| G3 | `single_ir` | SIRST-UAVB | 跨数据集（红外） | 强 |
| G4 | `single_ir` | IRSTD-1k | 跨数据集（红外小目标） | 强 |

> ⚠️ **标签来源（2026-09-22 修正）**：G1 用可见光标签（`labels/`）；
> **G2/G3/G4 的红外单模态模型必须用 `labels_ir/`（infrared.json）训练与评测**。
> 若用可见光标签训练红外模型，模型会学到"框偏 3.62 pp"的错误映射，
> 在外部数据集上评测时无法区分"泛化差"与"标签本身就错位"。

**训练命令**（单模态模型，同时服务于消融 A 组）：

```bash
# 可见光单模态（用 visible.json 标签，默认）
python train_full.py --route A --config baseline --single-modal rgb \
    --epochs 150 --name single_rgb

# 红外单模态（必须用 infrared.json 标签！）
python train_full.py --route A --config baseline --single-modal x \
    --label-from ir \
    --epochs 150 --name single_ir
```

**测试命令**（零样本推理，不微调）：

```bash
# 示例：G3 —— 用 single_ir 测 SIRST-UAVB
python predictMM.py \
    --weights ResTest/single_ir/weights/best.pt \
    --x-source <SIRST-UAVB 图像目录> \
    --name gen_G3_sirst
```

> **注意**：框架的 `predict` 接口用 `rgb_source=None, x_source=<路径>` 实现纯红外推理
> （见 `predictMM.py` 第 43–51 行的官方示例）。
> 需要先确认这些外部数据集的标注格式能转为 YOLO 格式。

### 2.2 融合机制专项泛化（G5）—— 本设计的核心

**背景**：可用的外部数据集都是**单模态**的，无法直接检验"融合机制"的泛化能力。
而模态填充（伪造缺失模态）不可靠——它生成的是可见光衍生特征，不含热信息，
模型行为未定义，结论无法解释。

**方案**：用**双模态模型做单模态退化推理**。

```
输入 = Anti-UAV410 的真实红外图（无伪造）
模型 = 双模态训练的完整模型（融合模块权重保留）
方式 = rgb_source=None，只走红外分支
```

**为什么这个方案成立**：

| 优点 | 说明 |
|---|---|
| 输入全真实 | 不含任何合成模态，无伪造成分 |
| 检验融合机制 | 用的是双模态训练的权重，融合模块在位 |
| 直击创新点 | 正是"模态缺失时退化降级"的实证 |
| 双重用途 | 同时服务于泛化实验与创新点论证 |

**命令**：

```bash
# G5：双模态模型在 Anti-UAV410 上做红外单模态退化推理
python predictMM.py \
    --weights ResTest/yolomm-baseline/weights/best.pt \
    --x-source <Anti-UAV410 图像目录> \
    --rgb-source None \
    --name gen_G5_fusion_degrade
```

**预期结论**：若融合机制泛化良好，退化推理的性能应显著优于
"纯红外单模态模型"（`single_ir`）——因为双模态训练让红外分支
学到了更鲁棒的特征表示。**这个对比就是核心证据。**

**对照设计**：

| 对照组 | 模型 | 输入 | 标签来源 | 说明 |
|---|---|---|---|---|
| 基准 | `single_ir` | 仅红外 | **`labels_ir/`** | 纯单模态，无融合知识 |
| 实验组 | 双模态模型 | 仅红外（退化） | `labels_ir/`（评 `ir` 头） | 有融合知识，模态缺失 |
| 上界 | 双模态模型 | RGB+IR | RGB + IR 双标签 | 完整输入（A300 上） |

> ⚠️ **G5 与双头架构的关系（2026-09-22 新增）**：
> 若使用 `dual-fusion`（双头）模型做 G5，评测应**只报 `ir` 头**的指标
> （`metrics/ir/metrics/mAP50-95(B)`），因为退化推理时只有红外分支有真实输入。
> 融合头在模态缺失时的表现应**单独说明**（它此时等价于退化后的融合，不是正常态）。
>
> 若使用单头 `baseline` 做 G5，则按原有方式报单一 mAP，但需说明该模型
> 从未接受过 IR 坐标系标签的监督，其在红外图上的框存在系统性偏移。

**G5 的增强版本（可选，若采用双头架构）**：

双头架构提供了一个**单头架构做不到的** G5 变体——同时检验两端的泛化：

| 编号 | 模型 | 测试输入 | 评测对象 | 说明 |
|---|---|---|---|---|
| G5-a | `dual-fusion` | 仅红外 | `ir` 头 | 模态缺失退化 |
| G5-b | `dual-fusion` | 仅可见光 | `rgb` 头 | 模态缺失退化（镜像） |
| G5-c | `dual-fusion` | RGB+IR | `fuse` 头 | 完整输入（上界） |

这组设计能同时回答"哪一侧退化更严重"，对工程取舍（如夜间只开红外）有直接指导意义。

## 三、鲁棒性实验（3 项）

全部在**自己的测试集**上施加扰动，无需外部数据。

### R1 模态失效实验（创新点的直接论据）

**目的**：量化"模态退化时性能如何衰减"，验证退化降级设计。

| 条件 | 实现方式 | 说明 |
|---|---|---|
| 双模态完整 | 默认 | 基准 |
| 仅 RGB | `--modality rgb` | 运行时消融 |
| 仅 IR | `--modality x` | 运行时消融 |
| RGB 降质 | 施加噪声/降亮 | 模拟夜间、雾天 |
| IR 降质 | 掩码/噪声 | 模拟热对比度下降 |

**双头架构下的报数方式（2026-09-22 新增）**：

| 条件 | 报哪一路指标 |
|---|---|
| 双模态完整 | 三路都报，重点是 `fuse` |
| 仅 RGB | 报 `rgb` 头（`ir` 头此时无真实输入） |
| 仅 IR | 报 `ir` 头（`rgb` 头此时无真实输入） |
| RGB 降质 | 报 `fuse` 头，看融合是否被拖累 |

> ⚠️ **不要对无真实输入的那一路报指标**——那是伪造/填充模态下的结果，不具解释性。

**框架已内置相关增强参数**（`default.yaml`），可直接用于训练期增强或测试期扰动：

```yaml
mm_modal_dropout_p: 0.0          # 随机擦除单模态某矩形区域的概率
mm_modal_dropout_area: [0.02, 0.15]   # 擦除面积比例范围
mm_modal_dropout_fill: zero      # 填充模式: zero|one|const|noise
mm_async_geo_p: 0.0              # 异步几何扰动概率
mm_async_geo_translate_px: [1, 2]     # 随机像素平移范围
mm_async_geo_rotate_deg: [-0.5, 0.5]  # 随机旋转范围（度）
mm_async_geo_target: x           # 扰动目标模态
```

> **提示**：`mm_async_geo_*` 用于 **R2 非对齐鲁棒性实验**——
> 通过设置不同的 `translate_px` 范围，在**实测天然偏移（3.62 pp）之上**叠加额外偏移，
> 模拟比现实更严重的视场漂移。注意：天然偏移本身无法消除，实验是在它**之上**做加法。

### R2 非对齐鲁棒性实验（**2026-09-22 重构**）

**旧设计作废说明**：原 R2 为"施加 0/2/4/8/16 px 配准误差，观察 mAP 衰减"，
其基准点（0px 理想配准）依赖人工配准，**已证实不可达**，故整节重构。

**新目的**：论证"两模态视场天然不重合"这一现实前提下，本方法**不依赖配准**且仍然稳健。

**核心论点**：本方法用**双套独立标签**（`labels/` + `labels_ir/`）从根本上绕开了配准问题——
每个检测头用**本相机坐标系下的真实框**监督，因此不存在"映射误差"这一误差源。

**实验设计（三个层次）**：

**层次 1：验证"不依赖配准"（主证据）**

| 模型 | 训练标签 | 实测 RGB-IR 框偏移 | 说明 |
|---|---|---|---|
| `single_rgb` | `labels/` | — | 可见光单模态上界 |
| `single_ir` | **`labels_ir/`** | — | 红外单模态上界（**注意标签来源**） |
| `dual-fusion`（双头） | `labels/` + `labels_ir/` | 3.62 pp（中位） | **本方法**，两端各自监督 |
| `late-ref`（单头） | 仅 `labels/` | 3.62 pp | 对照：单头在非对齐下的退化 |

**关键对比**：`dual-fusion` 的 `ir` 头 mAP vs `late-ref` 在红外图上的表现。
若前者显著更高，即证明"独立标签"有效绕开了非对齐问题。

**层次 2：量化"非对齐程度"与性能的关系（补充证据）**

用 `mm_async_geo_*` 参数**人为放大**两模态的视场差异，观察退化趋势：

```yaml
mm_async_geo_p: 0.0                  # 异步几何扰动概率，实验时设为 1.0
mm_async_geo_translate_px: [1, 2]    # 平移范围；实验时依次试 [2,2] / [8,8] / [16,16]
mm_async_geo_rotate_deg: [-0.5, 0.5] # 旋转范围
mm_async_geo_target: x               # 只扰动红外侧（模拟视场漂移）
```

| 附加平移 (px) | 叠加在实测 3.62 pp 之上 | 预期 |
|---|---|---|
| 0（仅天然偏移） | 3.62 pp | 基准 |
| +2 | ~4.2 pp | 几乎无衰减（验证鲁棒性） |
| +8 | ~5.6 pp | 轻微下降 |
| +16 | ~8.1 pp | 明显下降 |

**呈现方式**：折线图（x = 附加视场偏移，y = mAP50），
对比 `dual-fusion`（双标签）与 `late-ref`（单标签）两条曲线。
**预期 `dual-fusion` 曲线明显更平缓** —— 因为它不依赖跨模态坐标一致性。

**层次 3：跨模态一致性损失的贡献**

若启用 DFSC（`mm_dfs_weight > 0`），追加一条曲线说明语义一致性约束
是否进一步提升非对齐下的稳定性。

**论文呈现**：
1. 主表：四种模型在天然 3.62 pp 偏移下的 mAP（层次 1）；
2. 折线图：附加偏移 vs mAP，两条曲线对比（层次 2）；
3. 可视化：同一帧 RGB/IR 各自的检测框，直观看"两个坐标系都框准了"。

> ⚠️ **表述注意**：论文中不要写"我们解决了配准问题"，
> 正确表述是"**本方法不依赖配准**"——这是设计上的规避，不是工程上的修复。
> 这个区分很重要，审稿人会关注逻辑严谨性。

### R3 目标尺度分层实验

**目的**：展示模型在不同目标尺度上的表现，为 P2 头改进提供依据。

**已实测的目标尺度分布**（基于 28381 个训练标注）：

| 分位 | 归一化 | 640 输入下像素 |
|---|---|---|
| p10 | 0.033 × 0.035 | 21 × 22 px |
| p25 | 0.041 × 0.044 | 26 × 28 px |
| p50 | 0.057 × 0.054 | 37 × 34 px |
| p75 | 0.087 × 0.065 | 55 × 42 px |
| p90 | 0.110 × 0.074 | 70 × 47 px |

**分桶统计**：

| 桶 | 像素范围 | 说明 |
|---|---|---|
| 极小 | < 32 px | p25 以下，最困难 |
| 小 | 32–64 px | 主体分布 |
| 中 | > 64 px | 相对容易 |

**呈现方式**：分组柱状图（三个桶的召回率），对比"标准 P3/P4/P5"与"含 P2 头"两个配置。

| R3 | 尺度分层 | 自己 test | 分桶召回率 |

## 五之二、双头架构带来的评测变化（2026-09-22 新增）

若采用 `dual-fusion`（双头 + 融合分支）架构，上述所有实验的**评测环节**都要适配：

| 变化点 | 说明 |
|---|---|
| **指标键变为三套** | `metrics/{rgb,ir,fuse}/metrics/mAP50-95(B)` |
| **融合增益自动输出** | `fusion_gain_over_rgb` / `fusion_gain_over_ir` |
| **评测器自动切换** | `get_validator()` 检测到 `DualHeadFusionDetect` 自动改用分模态评测器，无需手动指定 |
| **报数时的坐标系声明** | 报 `ir` 头指标**必须注明**它用 IR 坐标系标签（infrared.json），与 `rgb`/`fuse` 不同源 |
| **不可跨模态比较** | 三路 mAP 只能各自与其单模态基线比，不能相互直接比大小 |

**对外部单模态数据集的处理**：外部数据集（DUT/Anti-UAV410/SIRST-UAVB/IRSTD-1k）
只有单模态，双头模型在其上评测时**只报有真实输入的那一路**：

| 外部数据集 | 输入 | 报哪一路 |
|---|---|---|
| DUT Anti-UAV（可见光） | 仅 RGB | `rgb` 头 |
| Anti-UAV410 / SIRST / IRSTD（红外） | 仅 IR | `ir` 头 |

融合头在单模态输入下无法得到有意义评测（缺一路真实输入），**不应报告其数值**。

## 七、需要提前解决的技术问题

| 问题 | 影响 | 应对 |
|---|---|---|
| **外部数据集标注格式不一** | G1–G4 无法直接评测 | 写格式转换脚本（DUT 的 VOC XML → YOLO txt） |
| **单模态数据集如何适配框架** | 框架需 RGB+IR 配对 | 单模态模型只需一路输入，需确认 `data.yaml` 写法 |
| **Anti-UAV410 未下载** | G2/G5 阻塞 | 优先下载 |

## 八、与消融实验的关系

两个清单的关系：

```
消融实验（20 组，含新增 A0 架构消融 3 组、B6 DFSC 消融）
  └─ 回答"我的设计有没有用"

泛化+鲁棒性（10 项）
  ├─ 泛化（5 项 + G5 增强版 3 项）：回答"能否迁移到新环境"
  └─ 鲁棒性（3 项）+ 真机（1 项）：回答"恶劣条件下是否可靠"

共享资源：
  ├─ single_rgb / single_ir 模型 → 同时服务消融 A 组与泛化 G1–G4
  │    ⚠️ 注意：single_ir 必须用 labels_ir/ 训练
  ├─ dual-fusion 模型 → 同时服务 A0 组、B6 组、R2 主证据、G5 增强版
  └─ baseline 模型 → 同时服务所有实验
```

**注意复用**：`single_rgb` 与 `single_ir` 是消融 A 组和泛化 G1–G4 的共同基础，
训练一次即可支撑两组实验。`dual-fusion` 则同时是 A0-2、B6、R2、G5 的核心，
**是本轮架构修订后复用度最高的模型**，建议优先训练并妥善归档。
