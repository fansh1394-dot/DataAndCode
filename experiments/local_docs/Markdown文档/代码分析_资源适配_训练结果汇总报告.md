## 第一部分 · 代码功能与架构分析

### 1.1 项目总体架构与数据流

本课题是一个基于 Ultralytics YOLO 深度改造的「非对齐 RGB-红外双光谱反无人机检测」工程。核心研究代码集中在 `MutilModel_3485988898/ultralytics/`，数据与实验流水线脚本在 `scripts/`。

```Shell
原始数据 Anti-UAV300 (visible.mp4 + infrared.mp4 + *.json)
        │  scripts/prepare_mm_dataset.py  (--pair-policy any/both --label-from dual)
        ▼
多模态数据集 uav_data_v2/
   images/{split}/<stem>.jpg      RGB 主模态
   images_ir/{split}/<stem>.jpg   IR 次模态（同名配对）
   labels/{split}/<stem>.txt      RGB 标签
   labels_ir/{split}/<stem>.txt   IR 标签
   metadata/{split}.json          valid_rgb / valid_ir / kind / sequence / frame_index
   data.yaml                      modality / labels 映射 / Xch
        │  YOLOMultiModalImageDataset + collate
        ▼
batch = { img:(B, 3+Xch, H, W), bboxes/cls/batch_idx,
          bboxes_ir/cls_ir/batch_idx_ir, valid_rgb/valid_ir/frame_kind }
        │  DetectionModel.forward → BaseModel._predict_once
        ▼
① MultiModalRouter.setup_multimodal_routing(x)  # 按通道数切 PRIMARY/SECONDARY/FUSED
② route_layer_input                            # 5 字段层路由 'RGB'/'X'/'Dual'
③ [可选] 融合颈 RGB 半边随机屏蔽（仅 training）
④ 双路主干：RGB 支路 L0-10 / IR 支路 L11-21（空间重置）
⑤ 三条并行 neck：RGB neck L22-33 / IR neck L34-45 / 融合 neck L46-51
     融合节点 46/48/50 = Concat | ReliabilityAwareFusion | GatedReliabilityFusion
⑥ 检测头：rgb(L52)←RGB标签  ir(L53)←IR标签  fuse(L54)←RGB标签  [fuse_ir(L55)←IR标签]
        │
   ┌────┴──────────────────────────┐
   ▼                               ▼
训练 DualHeadFusionCriterion    验证 DualHeadDetectionValidator
 = 分路检测损失 + DFSC            · 主指标=fuse(RGB坐标系)
 + 头间/对间一致性                · 每分支/每子集(both/only_rgb/only_ir)独立 DetMetrics
 + (S7)drop-RGB 下 fuse←ir 蒸馏
```

### 1.4 核心机制说明

1. **双模态数据路由**：输入 6ch（3 RGB + 3 IR）时零拷贝切分为 PRIMARY/SECONDARY/FUSED；YAML 中 `layer[11]` 标 `'X'` 且 `from=-1`，触发 IR 支路空间重置（两模态原始分辨率不同）。
2. **融合颈机制**：三条并行 neck 在 L46/48/50 三个尺度融合。`Concat`（基线 N 系列）/ `ReliabilityAwareFusion`（凸组合 `w0·rgb_warpped + w1·ir_warpped`，`w=softmax`，含局部 offset + grid_sample 对齐）/ `GatedReliabilityFusion`（残差 `base + g·(ir−rgb)`，`g=sigmoid`，可离开凸包）。offset 与 gate 均 zero-init，保证起点中性。
3. **双头验证机制**：一次前向、多套指标；主指标取 `fuse` 头且只统计 `valid_rgb=True` 帧；`ir`/`fuse_ir` 用 IR 标签与 `batch_idx_ir`。
4. **子集处理**：`frame_kind` 编码 `0=both / 1=only_rgb / 2=only_ir`；`ir`/`fuse_ir` 头只分配 `both/only_ir` 子集，`rgb`/`fuse` 头只分配 `both/only_rgb`。
5. **非对齐契约**（`test_non_aligned_contract.py`）：校验 images/images_ir/labels/labels_ir/metadata 一一对应，且 `kind` 与 `valid_rgb/valid_ir` 推导一致。
6. **DFSC**：以目标中心为锚点在两分支特征图上做余弦一致性约束，天然免疫视场偏移，仅在 `valid_rgb & valid_ir` 帧生效。

### 1.5 已识别的设计约束

- 模型被构建两次（`Model._new` 与 `trainer.get_model`），任何训练期随机机制必须**默认关闭 + trainer 装配**，否则污染多头 stride 推断与既有权重推理。
- `mm_*` 参数不在 `check_cfg` 白名单，必须写入 `default.yaml` 否则硬崩，但校验责任落在 `train_full.py`。
- `fuse_ir` 是训练分支而非推理分支；损失与验证列名必须按 `train_branch_names`（12 项）展开。
- IR 与 RGB 目标数可不同，IR 分支必须用 `batch_idx_ir`。

### 2.2 分资源适配结论

**可直接复用（低改造）**

- **GeoShape 相似度标签分配（COXNet）**：替换刚性 IoU 分配，改善小目标定位，改造面小、收益明确，与本项目 YOLO 系工程栈兼容度高。
- **外部基准数据集与协议**：`RGBT-Tiny`（243★）、`DroneVehicle`（748★）用于跨数据集泛化论证（不参与本域训练，遵守既有硬约束）。
- **综述索引**：`Awesome-RGBT-Fusion`（767★）、`Awesome-RGBT`（240★）作 related work 检索入口。

**需改造后适配（中改造）**

- **DAMSDet 可变形交叉注意力 → 替换融合颈 L46/48/50 的刚性 Concat**：自适应采样天然缓解局部失配，是本项目最值得移植的算子。但 DAMSDet 是 DETR 系，只移植融合算子、不移植检测头。
- **COXNet 小波对齐 CLFM → 替换/补充 `ReliabilityAwareFusion` 的 offset grid_sample**：频域分解对动态背景与非均匀错位更稳健。
- **C²Former 的 ICA + AFS → 作为模态失校准校准插件嵌入 backbone 尾部**。

**建议自研（缺口最大，形成创新点）**

- **跨模态时序对齐模块**：开源覆盖几乎空白（GitHub `unaligned RGBT detection` 命中 0 条），可借鉴 DHNet「时序+空间双关联」思想并轻量化。
- **对齐-融合-监督联动的归因诊断**：扩展 `diag_fusion_attribution.py`。

**建议规避**

- 整体迁移 CFT：固定 8×8 pooling 抹除小目标稀疏细节。
- 整体迁移 DAMSDet 原实现：与 YOLO 系栈差异过大。

### 4.1 优先级排序

|    优先级    | 改进项                                        | 依据                            | 预期收益                         |   改造量   |
| :----------: | --------------------------------------------- | ------------------------------- | -------------------------------- | :--------: |
| **P0** | 引入门控激活正则`L_gate`（B4-c）            | 门控 L48/L50 冻结于 0.5         | 恢复门控区分度                   |     小     |
| **P0** | 把`fuse_ir` 头纳入主指标与论文主表          | 困难子集 fuse_ir≈ir，fuse≪ir  | 直接支撑「双坐标监督有效性」主张 |     小     |
| **P1** | 对称监督：提高`w_fuse_ir`（B4-b）           | 可解码性 AUC=0.972 指向监督问题 | 强迫融合特征学习 IR              |     小     |
| **P1** | 用 DAMSDet 可变形交叉注意力替换 offset 对齐   | 局部失配建模更强                | 提升 only_ir/both 对齐           |     中     |
| **P1** | 移植 COXNet 小波对齐 + GeoShape 标签分配      | 小目标 + 动态背景               | 小目标定位改善                   |     中     |
| **P2** | 自研跨模态时序对齐模块                        | 开源空白，unique 创新           | 论文核心贡献                     |     高     |
| **P2** | 扩展`diag_fusion_attribution.py` 加时序维度 | 归因证据链                      | 消融证据                         |     中     |
| **P3** | 跑满 A4/S4/S7 与 abl 系列                     | 当前结论不完整                  | 严谨对照                         | 小（时间） |

### 4.2 需要明确否决的方向

- **S7 蒸馏路线（drop-RGB 下 fuse←ir）**：实测失败（ep70 时 gain_over_rgb = −0.0132，为所有完成实验中最差）。根因是 teacher（ir 头）弱于 student（fuse 头）时的向下蒸馏 + 跨坐标系响应不对齐，S8a 已去掉蒸馏（`w_fuse_ir_distill=0.0`），方向正确。
- **单纯提高 mask 强度**：S4（0.5）比 S3（0.2）更差（fuse 0.696 vs 0.706），说明 mask 过强会损伤 RGB 通路。
- **整体迁移 CFT / DAMSDet 原实现**：架构栈不匹配。

### 4.3 建议的实验补齐清单

1. 等 `v2_S8a_s0` 跑完（当前 ep38/100），对比 `w_fuse=2.0` 是否恢复 fuse 独立性。
2. 补跑 A4（mask 0.1）与 S4（mask 0.5）至 100 epoch，形成 mask 强度梯度：0.1 / 0.2 / 0.3 / 0.5。
3. 补跑 `abl_B1-2`（modal dropout）与 `abl_A0-2` 至完整轮次，补齐 DFS 权重消融。
4. 统一在**困难子集**上报告 `fuse` / `fuse_ir` / `ir` 三头并列指标。
5. 论文主表采用 150ep × 3 seed（当前均为 100ep × 1 seed，统计效力不足）。
