主线一 · B1 专项链（当前焦点）

融合头双坐标系监督：给融合分支增设 fuse_ir 头，用 IR 坐标系标签监督，解决「仅红外可见时融合头失效」问题。

阶段内容状态通过判据
B1-0 仅加开关与配置骨架，fuse_ir=None 已完成 回归 31/31；三路 mAP 与 best.pt 逐位一致
B1-1 fuse_ir 头 + L2 监督（不加 L3） 已训·待评测 困难子集 A 组 fuse > 0.1（基线 0.0011）
B1-2 开启 L3-b 跨头一致性约束 在跑·参数不符 A 组 fuse 进一步提升；主集 fuse mAP50-95 ≥ 0.69
B1-3 消融 ir_consist_weight ∈ {0, 0.05, 0.1, 0.5} 待做 找到最优权重区间
⚠ 当前运行参数与阶段定义不符 服务器上正在跑的是： 
python train_full.py --config dual-fusion-b1 \
  --mm-modal-dropout 0.3 --epochs 100 --batch 64 \
  --name abl_B1-2_modal_dropout
其中 --mm-modal-dropout 0.3 是数据侧 S2 增广（随机擦除单模态区域）， 而文档定义的 B1-2 是损失侧 L3-b 一致性（--mm-dual-w-fuse-ir-consist 0.1）。
  • 该 run 实质是「B1-1 + S2 增广」，建议改名为 abl_B1-1b_modal_dropout；
  • 否则无法区分增益来自 dropout 增广还是 L3-b（因为 L3-b 根本没开），论文归因会串；
  • 真正的 B1-2 需补跑：--mm-dual-w-fuse-ir 1.0 --mm-dual-w-fuse-ir-consist 0.1。
最紧急的一步：先评测 B1-1 成本几分钟，却决定整条链走向——若 A 组 fuse 已 > 0.1，说明监督层面就是主因，可直接推进 B1-2； 若仍接近 0，说明问题比监督更深（需结构改造），应及时止损转向 S1 数据配套。建议在 B1-2 训练期间并行执行： 
python scripts/eval_hard_subset.py \
  --weights ResTest/abl_B1-1_dual_ir_head/weights/best.pt \
  --data /root/rivermind-data/uav_hard/data.yaml \
  --imgsz 640 --batch 48 --device 0 --groups

⚠ 报数铁律（审稿人必查）
  • 三路 mAP 键为 metrics/{rgb,ir,fuse}/metrics/mAP50-95(B)，不可跨模态直接比较，只能各自与其单模态基线比；
  • 报 ir 头必须声明它使用 IR 坐标系标签（infrared.json），与 rgb/fuse 不同源；
  • 外部单模态数据集只报有真实输入的那一路（DUT 报 rgb，红外数据集报 ir），融合头不可报数；
  • 论文中写「本方法不依赖配准」，不要写「我们解决了配准问题」——前者是设计规避，后者是工程修复，逻辑严谨性会被追问。
