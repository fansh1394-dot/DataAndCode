# E36 三类检测器（bird / drone / other）

- 日期：2026-11-11
- 初始化：`nc3_init.pt`（E28c last 扩头，bird/drone 分类通道复制，other 随机初始化）
- 数据：`bd_nc3` train 21 582（基础 18 416 + 合成 other 3 166，14.7%；other 框 4 611）/ val 1 471（合成 239）
- 训练：batch 32、640、20 ep、lr0 0.002；平衡 val 最佳 0.5069 @ep15
- 评测权重：`best.pt`

|---|---|---|---|---|---|
| AVID bird (2 700) | 81.3% | — | **2.74%** | 0.19% | 15.7% |
| AVID drone (3 680) | 78.6% | 0 | — | 0 | 21.4% |
| Mendeley drone (531) | 94.0% | 0 | — | 0 | 6.0% |
| 合成 other (334) | 91.3% | 0 | **0.30%** | — | 8.4% |

对照 E28c（二类，同口径）：AVID bird → drone **1.78%**、bird 漏检 18.0%、drone 漏检 24.2%。

## 3. 结论

1. **other 类有效**：合成 other 上 91.3% 判对，只有 **0.3%** 被判成 drone——直接对应“气球误告警”的风险，远低于 2% 目标。
2. **代价可控**：Mendeley −1.5 pp（0.739→0.724）、AVID drone −1.1 pp，bird AP 反而 +0.8 pp。
3. **新的安全项**：bird→drone 从 1.78% 升到 **2.74%**，是三类化后最需要处理的指标；单帧阈值与 K=5/N=3 轨迹投票（E32）应能压下去，但不能只靠 mAP 判断。
4. **合成不等于真实**：other 的 0.660/91.3% 只证明链路可用，真实气球/风筝仍需 100–200 帧做 held-out，否则论文只能标注 synthetic。

## 4. 下一步

- 先做阈值标定 + 轨迹级评估（E32）：以 bird→drone 误告警、drone 漏告警是否 0 为判据；
- 再决定是否需要补真实 other 帧，或通过 hard-negative 采样进一步压 bird→drone。
