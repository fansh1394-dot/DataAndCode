## 2. 研究背景与痛点现状分析

### 2.1 应用背景

低慢小（low-small-slow）无人机在机场、能源设施、大型活动等近场保护空域构成非合作威胁：
雷达受低空杂波与 RCS 限制、射频手段对静默飞行失效、声学手段受距离与噪声制约。
可见光 + 长波红外双光谱是近场监视的独立证据源：可见光提供纹理与轮廓，红外提供热特征与夜间能力。
但双光谱系统从"能拍"到"能测"之间存在四道工程与科学鸿沟，构成本文档四个题目的共同背景。

### 2.2 文献现状四象限

| 象限 | 代表工作 | 现状判断 |
|---|---|---|
| 假设已配准的特征融合 | CFT（480★）、YOLOv11-RGBT（729★）、YOLO-MIF（264★）、DEYOLO（185★）、ICAFusion | 高度饱和，增量内卷 |
| 处理非对齐的融合 | DAMSDet（73★）、CMAI-Det（10★）、COXNet（9★）、IM-CMDet（4★） | 活跃但小众；共同做法是"估计偏移→对齐特征"，未质疑标注坐标语义 |
| 模态缺失/退化鲁棒 | missing-modality 系列、modality dropout、质量感知门控 | 已成体系；但全部在推理时"猜"哪路失效，无可见性真值监督 |
| 边缘部署 | 各类轻量化 + 量化 + NPU 部署 | 工程成熟；双光谱双流 + 帧级路由上板的完整系统未见报告 |

### 2.3 四个核心痛点（实测）

**痛点 P-1：融合方法的隐式"共享坐标"假设在真实双光谱数据上不成立。**
本项目两套人工标注：RGB 标注机体、IR 标注热源。核验结果（train/test 全量）：
目标数量 100% 一致、类别 100% 一致（单类 UAV），但框位置 IoU 均值仅 0.0432，
85.2% 的帧 IoU < 0.10，配对框 IoU ≥ 0.5 仅 2.6%；偏移 97.75% 单向（dy 中位 35.33 px，
约 1.1 个目标高度）；IR 图最亮点（热斑）到 IR 框中心残差中位 5.59 px、到 RGB 框中心 44.07 px
（比值 7.88×），97.2% 的 IR 框更靠近热斑。数量与类别的一致性排除了漏标与标注噪声的解释——
两套标注指向同一目标的两个不同物理部位，这是成像机理差异，不是标注缺陷。
而上述高星开源方法全部假设两模态共享一套坐标监督。

**痛点 P-2：特征级融合增益在正式口径下坍缩。**
test 上 `fusion_gain_over_rgb` 仅 +0.0016（融合头 0.558835 反低于纯 RGB 基线 0.568257 达 −0.0094）；
监督修复、融合算子改造、坐标系切换、训练期表达式等七条修复路线全部否定。
唯一稳定的正增益出现在单模态可见帧（only_rgb 桶 +0.0101）——融合的价值在可见性互补，
不在特征融合质量。

**痛点 P-3：几何配准两头堵死。**
偏移生成结构为 `dy = A(seq) + B·(cy−0.5) + ε`：视差项解析可算（B ≈ −89~−130 px/单位 cy，
序列内 corr(dy,cy) 中位 −0.59/−0.73，85~95% 序列负相关）；序列偏置 A 跨序列 std 15~21 px
（范围 [−75, +101]），但前 4~8 帧在线可估（std(A) 中位 1.2 px）；帧内抖动 ε ≈ 5 px，时间常数 2 帧。
可实现的对齐（序列级仿射，N=64 帧拟合）中位残差 15.51 px = 0.6 个目标高度；
而 per-frame oracle（构造性零误差）重训早期融合仍为 −0.0010。
完美对齐无收益、可实现对齐精度不足——"先配准再融合"不是可行路线。
这同时从机理上解释了 IoU 关联必然失效（97.4% 帧 IoU < 0.5）。

**痛点 P-4：端侧实时与双流成本矛盾。**
RK3588 仅 6 TOPS INT8；双模型 CPU fp32 约 250 ms/帧；双光谱双流推理 + 帧级路由的完整
板端系统（采集→双路推理→NMS-free 解码→路由→告警）在公开文献中未见报告。

## 5. 题目一：双坐标系标注语义不一致（发现型）

### 5.1 定位

| 项 | 内容 |
|---|---|
| 题目 | 《可见光-红外目标检测中的双坐标系标注语义不一致：量化、成因与检测影响》 |
| 英文 | Dual-Coordinate Annotation Inconsistency in Visible–Infrared Object Detection: Quantification, Causes, and Detection Impact |
| 形态 | 数据集分析 + 基准 + 边界界定（方法增量最小） |
| 周期 | 4~6 周（诊断已齐备，剩 1 个判定实验 + 写作） |
| 期刊梯度 | 冲刺 Information Fusion；主投 IEEE TIM / TGRS；保底 Remote Sensing / Neurocomputing |
| 旧版映射 | 取代旧题一的动机部分 + 旧题四的 B5 上界议题 |

### 5.2 背景与痛点

多光谱检测文献普遍假设训练标注在两模态间共享坐标（同一套框复制给两路输入，
或单套框配准后使用）。该假设在双相机吊舱（不同焦距、不同安装角、不同成像机理）上是否成立，
没有任何工作系统量化过。本项目实测（V1~V4）：数量类别全一致但位置 IoU 仅 0.043，
属"语义不一致"而非"标注噪声"——这直接动摇"共享坐标监督"这一隐式前提的合法性。

### 5.3 科学问题与关键问题

**科学问题**：当两个传感器对同一目标标注不同物理部位时，共享坐标监督的融合方法会发生什么？
标注语义差异能否解释融合增益坍缩？

| 编号 | 关键问题 | 对应证据 |
|---|---|---|
| KQ-1.1 | 如何在不依赖训练的前提下，证明两套标注不一致且排除标注错误？ | 三层一致性核验协议（V1/V2/V4） |
| KQ-1.2 | 偏移是否具有可建模的生成结构？可实现对齐的精度极限是多少？ | V5~V7 |
| KQ-1.3 | 把标注差异完全消除（oracle）后融合是否恢复增益？ | V8（−0.0010）+ R1.1 待判定 |
| KQ-1.4 | 该现象对 IoU 型标签分配与评测协议的影响如何定量？ | 97.4% IoU<0.5 → TAL/IoU 关联失效机理 |

### 5.4 创新点声明（每条可证伪）

| 编号 | 创新点 | 证伪方式 |
|---|---|---|
| CN-1.1 | 首次系统量化双坐标标注语义不一致：三层核验协议（数量/类别/几何） | 在公开双谱数据集上复现失败 |
| CN-1.2 | 偏移生成模型 `dy = A(seq)+B·cy+ε` 及其三层可处理性界定 | 模型在留出序列上预测失效 |

| CN-1.4 | IoU 关联失效的定量机理（残差/目标尺度比 = 0.6） | 反例：小目标 IoU 关联仍高召回 |

## 6. 题目二：序列自适应偏移先验的跨坐标关联（方法型）

### 6.1 定位

| 项 | 内容 |
|---|---|
| 题目 | 《基于序列自适应偏移先验的非配准双光谱目标关联与检测》 |
| 英文 | Sequence-Adaptive Offset Prior for Cross-Modal Association in Unregistered RGB–IR Detection |
| 形态 | 传统方法论文：检测器 + 关联模块 + 一致性损失 |
| 周期 | 8~10 周 |
| 期刊梯度 | 冲刺 IEEE TIP / TMM；主投 IEEE TIM / Neurocomputing；保底 SPIC |
| 旧版映射 | 承接旧题一"目标级坐标关联 + 仲裁"，去掉可靠性头，换成偏移先验 |

### 6.2 背景与痛点

非对齐融合方法（DAMSDet/COXNet 等）在特征层估计稠密偏移，本项目已证明其收益为零（V8/V9）。
但"两个坐标系各自检测后，如何知道两边的框是同一个目标"仍未解决：IoU 关联在 0.6 个目标高度的
系统偏移下必然失效（V7），而文献中的跨模态关联全部以 IoU 或像素对应为基础。

### 6.3 科学问题与关键问题

**科学问题**：在无法配准（残差 15+ px）且 IoU 失效的双坐标检测输出之间，如何建立可靠的
目标级对应，并利用对应关系提升检测？
